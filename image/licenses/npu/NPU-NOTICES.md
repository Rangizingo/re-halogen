# halogen: notices for the NPU (HALOGEN_NPU_MODELS)

This covers two things: the NPU engine binary in this image
(`/usr/local/bin/halogen-npu`), and the NPU files it loads at run time. Those
files are each model's `devices/` directory and weight file, and they are
fetched like model weights, not carried in the image. A copy of this file
travels with every published set of NPU files, as `devices/NOTICE.md`.

## In the binary: XRT's public headers (Apache-2.0)

`halogen-npu` is compiled against the public C++ headers of AMD's XRT, commit
`0026185de81a179dc7d886197d3e35f9a179b4e8` (release 2.25.37). Code from those
headers, such as inline functions and templates, is part of the binary. XRT's
license and notice are reproduced in full beside this file:

| file | what |
| --- | --- |
| `XRT-LICENSE` | XRT's LICENSE at that commit: its userspace code under the Apache License, Version 2.0 |
| `XRT-NOTICE` | XRT's NOTICE at that commit |

Every header the binary includes names Apache-2.0. Four of them (`xclbin.h`,
`ert.h`, `xrt_mem.h`, `xclerr.h`) are shared with XRT's kernel drivers and
also name GPL-2.0. XRT's LICENSE places all of its userspace code under
Apache-2.0.

The XRT libraries themselves are **not** in this image. The binary uses the
host's XRT, mounted read-only at `/opt/xilinx/xrt`.
