## Method

- Classified each gap by the vendor use line. Scripts compared the shape of every use across all matching instances (for example all 460 uses of 0x1b are the same five-op signed K/32 sequence; all 44 linear gaps equal (2U-1)*B).
- E when the literal is a fixed-geometry constant (tile size, K, unroll offset), an index step, a sign fix of a division the rewrite writes the same way, a lane selector, or a launch constant, and the rewrite covers the same element set another way.
- Bounds that depend on a runtime input got reaching specs (below). All 1,472 case rows MATCH bitwise (rewrite/tables/g30.md), so no bound is R.
- Negative control (rewrite/tables/g30-negctl.md): lq4w.hip:52 patched to G-1 above 128 gives MISMATCH at G=129 and 300 only; linear_q4.hip:89 patched to drop the last element above K=1000 gives MISMATCH at K=1001 and 1002 only. The thr and linear runs would have exposed a bound error.
