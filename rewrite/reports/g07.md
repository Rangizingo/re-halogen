## Findings worth keeping

- Plain `logf` in hipcc differs from the vendor ln(theta) by 1 ulp for some inputs (theta 1e6, 495000 mismatched; 10000 hid it). The vendor expansion is spelled out as `vlog` (rope.hip, qk.hip). Cause found by disassembling the rewrite: clang fused `p + n` into an extra fma. Every file now has `#pragma clang fp contract(off)` and writes each fma explicitly.
- FdRows (160 B by value) layout: 8 pointers at +0, 8 pointers at +64, 8 ints at +128 (kv.hip). Meaning per kernel: scatter/qk use K-pool and V-pool pointers plus a slot; attn_fd uses K pool, V pool and the last position.
- k_kv_bt layout was recovered with an iota run on Ai-core (c tile = 16-column chunks of 4 rows, d tile = [column][row]); rows past n write zeros.
- attn_fd: 4 key groups x 2 waves; per 16-key tile scores via v_dot2_f32_bf16 + xor butterfly (16,8,4,2,1), online softmax per tile, group merge 1..3 into 0 in order. `<true>` differs only in key addressing (block table `a[b*x208 + pos>>2]` for pos < 4*bb[b], else tail rows from `(len+1)&~3`).
- attn_fa2 (dense semantics): WMMA 16x16x16 bf16, 16 chained k-chunks for S, key tile 16. X=1 instances: scale 0.0625*log2e folded, exp2 with a -126 denormal guard. X=0 instances: scale 0.0625, full expf expansion. All other template args (B, C, OPT, Y, A) produced identical output in dense mode; A and Y only change the launch shape. Epilogue: out = bf16((O * (1/l)) / (1 + expf(-gate))) with gate at row*12288 + head*512 + 256 + d. Argument 5 is the gate, not a bias (always read; null faults).
- Keys >= m are NOT masked in fa2 or fa (loads clamp to row m-1); only the causal limit `key <= row + sel[0]` applies. Confirmed with sel[0] = 13 and 26 so that row positions exceed m.
- Row positions are `row + sel[0]`; the first KV tile sentinel is -1e30 (0xf149f2ca), alpha is only computed when m_old > -1e29.

## Not exercised (honest limits)

- attn_fa2 sparse mode: FaSel is all zero in every spec (dense only, as the host does in dense mode; +0x1c = 512). Tile bitmask (+0x00), per-row id lists (+0x08), counts (+0x10) are not modelled. B, C and the sparse paths of the 22 non-default instances are therefore proven equal to the default only in dense mode.
- attn_fa2 with n or m not multiples of 16 is covered (N=48, 100 with m = N+8, bases 0, 13, 26); A=2 buffers are padded to 32 rows.
- k_attn / k_attn_sel: block 256 and 128 only; n at most 2052 (LDS).
- k_qk_prep needs block 256 (reductions), tokens <= 8 (FdRows).
- Clamp constants inside the fa2 expf/expneg (x < -103.28, g > 104.56, g < -88.72, -126 guard, -1e29 sentinel) cannot change a bf16 output: they only alter terms that are below one float ulp of the row maximum or overflow identically. The edge specs (q,k +-40, gate +-120) run through those branches and MATCH; negative controls on them print MATCH (see below), so they are not proven by output, only by the instruction match.
