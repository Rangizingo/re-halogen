## What the kernel is (every point proven by MATCH)

Gated delta rule, 16 rows per group, grid 48 (one workgroup per head h, key head h/3), block 256 (8 waves). Args: 0 bf16 rows [row][10240] = q 2048 | k 2048 | v 6144,
8 g f32 [row][48], 16 beta f32 [row][48], 24 state f32, 32 idx, 40 n, 48 out bf16 [row][6144], 56 nrows, 64 Py (timing), 72 DnfTaps (40 B: int idx[3], pad, ptr[3]),
112 DnfNorm (24 B: ptr[3]). State base = state + n floats + idx[0]*0x9000000 bytes + h*16384 floats, layout [128 key][128 value].
The state sits in registers as S*256 (lane holds column 16w+(lane&15), rows lh+2m). Per group, see the header of `dn_fused16.hip` for steps 1-9 with cites. Key facts:

- q,k sums of squares: ((x0^2+x1^2)+(x2^2+x3^2))+((x4^2+x5^2)+(x6^2+x7^2)) per 8 bf16, xor-add over 16 lanes, +1e-6, guarded rsq (the guard branch is unreachable because x >= 1e-6),
  qscale = rsq(128.0) * rsq(q), kscale = rsq(k) (`@20F90-@211C4`). `rsq(128.0)` must be the hardware `v_rsq_f32` result; the rewrite hides the constant from the compiler (asm barrier) so it is not folded.
- gcum is a sequential f32 prefix sum, first element `g0 + 0.0` (`@21268-@213AC`), per 16-row group (the state decay is exp(gcum[15])).
- Gram: bf16 WMMA over 8 dim blocks, wave 0 K.K -> strictly lower L (`-ex * beta_i * ks_i * ks_j * acc`), waves 1+ Q.K -> Hq (lower incl. diagonal, f16 of 16*value). Forward substitution
  x = (I-L)^-1 e_j, descending fma chains. hi/lo f16 split of `bk[m]*x_m` and `beta[m]*x_m` (hi = f16(fma(c,x,0)), lo = f16(c*x - hi)).
- WMMA K-slot order is natural (slot k = row/dim k) everywhere; accumulator chains: lo before hi, dim blocks ascending, zero start.
- `expf` is the library expansion and matches the vendor's inline expansion, including exp underflow (g = -120) and overflow (g up to +8 per row, inf * 0).
- Taps: after the state update, if `idx[k] == rows done` (16, 32, ...), store S*(1/256) to `ptr[k] + h*16384 + row*128 + col` (state layout). k = 0,1,2 are independent compares (two can fire together). Proven by `dn_fused16_taps`.

## Variants (template bools b1, b2, b3; N = probe id)

- **N = 1..12 (b all false)**: same outputs as N = 0 (the diff adds realtime-clock reads and a `Py` store; `Py` not compared). MATCH using `k_dnf_p0`.
- **b1 = true**: Gram without WMMA. Thread (i, j) sums over d ascending in f32: `aL += (ks_j*K_j[d]) * (beta_i*(ks_i*K_i[d]))`, `aH += (qs_i*Q_i[d]) * (ks_j*K_j[d])` (plain mul and add,
  no fma), then `L = aL*(-ex)` (j<i), `Hq = f16(16*(aH*ex))` (j<=i) (`@163A8-@16884`). Rest identical.
- **b2 = true**: the MS and QS products use S split in two f16 parts: S = S256*(1/256), hi = f16(16 S), lo = f16(fma(S,16,-hi)); per dim block the chain is `acc += A*lo` then `acc += A*hi`
  (`@1D15C-@1D33C`; the register range v[58:65] is lo). The state update itself is unchanged.
- **b1 and b2 together** (`<0,true,true,false>`): the two changes combine, no other difference found (MATCH).
- **b3 = true**: DnfNorm is live: p0 = weight bf16[128] (shared by all heads), p1 = z gate bf16 [row][6144], p2 = result bf16 [row][6144]. `out` (arg 48) is NOT written.
  The group output o (bf16 RNE of the usual value) goes to LDS, then per row (rows < nrows): partial P[l] = (o[l]^2+o[l+64]^2)+(o[l+32]^2+o[l+96]^2); Q[j]=P[j]+P[j+16]; D = ((A0+A4)+(A2+A6))+((A1+A5)+(A3+A7)) with A_i = Q[i+8]+Q[i];
  r = guarded rsq(D*(1/128) + 1e-6); each lane handles columns 4l..4l+3: `sig = 1.0f/(1+v_exp(z*-log2e))` (IEEE division, hardware exp2), `result = bf16RNE(sig * ((r*o)*w))` (`@AA3C-@B574`, last group in the epilogue `@E6F8-@F40C`).
  The vendor pipelines this one group behind (reads LDS and z of the previous group); per-row numerics are the same, so the rewrite does it right after each group. Not covered: p1 aliasing `out` or p2 (the vendor reads z from global memory).
