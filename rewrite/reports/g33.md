## sample, accept, resid, smpg_pick/rpick/accept (lead)

- 0x1000000, 0x10000 (V:553/675 sample, 1804/1926 accept, 3298/3420 resid): radix pass 2/3 test `(key ^ prefix) < 2^24 / 2^16`. Rewrite `smpg_common.h:126,130` and `sample.hip:62,66`: `lim = 1u << (32 - 8*(lv-1))`, same value; clang compiles it as `lshr s18` + `v_cmp_eq 0` (ISA `6e522b12bbd2.dis:455-456`) because the loop is rolled. E.
- 0x7f800000 (V:1213,1242 sample; 2333 accept; 4321 resid; 6359,6393 pick; 6694 accept_final; 8341 rpick): this is not an integer test. It is `v_cmp_gt_f32 0x7f800000(+inf as float), |l2|` inside the ln fixup. Rewrite `smpg_common.h:189` writes `inf > fabsf(l2)`; clang folds it to `v_cmp_class_f32 0x1f8` (ISA `6e522b12bbd2.dis:892,916`). Mask 0x1f8 = bits 3..8 = -normal, -denormal, -0, +0, +denormal, +normal. Cases: NaN false/false, +-inf false/false, +-0 true/true, denormal true/true (even if f32 denormals were flushed, 0 < inf). Same predicate in the source, so no reaching spec was added. E.
- 0x404 (pick, V:6069,6073) and 0x40c (rpick, V:7808,7812,8019,8023): `v_mov` of an LDS byte address feeding `ds_store_2addr`/`ds_load_2addr`. Not a bound. Rewrite uses its own `__shared__` (`smpg_pick.hip:23-25`, `smpg_rpick.hip:29-31`). E.
