## What the scan3 kernel is (all proven by a bitwise MATCH of the E=0 base)

Chunked delta-rule scan, one block per (head h = blockIdx.x in 0..47, column slab y = blockIdx.y in 0..A-1), 128 threads,
slab width CW = 128/A, token rows per pass RT = A (thread = row tid/CW, column tid%CW). Kernarg: keys@0 (never read),
q@8, kk@16, g@24, v@32, w@40, a@48, st@56 (state in/out), idx@64, n@72, o@80 (bf16 out), k@88. Details and listing cites are
in the header comment of dnc_scan3.hip (base kernel `@12bc00`, listing line 154482). Per 64-token chunk: e0=exp(g_t),
e1=exp(g_63-g_t); pass 1 u = v - sum_j w[t][j]*S[j][col] (sequential fma, j ascending); pass 2 o = bf16_rne((sum_j
q[t][j]*S[j][col]) * e0 + sum_{j'<=t} a[t][j']*u[j'][col]) for t < k; S *= exp(g_63); S += sum_t (kk[t][j]*e1[t])*u[t][col]
(sequential over t). State is st + n + idx[0]*0x2400000 + h*16384 + y*CW floats.

## U12: scan3 template args B, C, D, G

Method: instances differing in one arg only, both run against the same rewrite, both MATCH bitwise (seed 1, N=128; table rows
from seeds 1,2,3 and N=128,197 where listed in g16.md). The rewrite has no parameter for B, C, D or G, so each has no numeric effect.
- A = grid.y = column slabs (r3). Rewrite parameter. A in {2,4,8,16,32} all MATCH.
- B: <8,16,0,F>, <8,8,0,F>, <8,4,0,F>, <8,2,0,F> (A=8, C=0, D=F) all MATCH the same A=8 rewrite; also <4,16>,<4,8>,<4,4>,
  <16,16>,<16,8>,<32,16>,<32,32>. B changes code size and barrier count (r4) with identical results, so B is a tiling/unroll
  choice with no effect on values. Which tile dimension: inferred only (not proven).
- C: <8,8,{0,4,8,16,32},F> all MATCH. C=0 is the 3119-line fully unrolled form, C in 4..32 the compact form. Results identical,
  C is a layout/unroll constant (r3/r4 measured LDS-offset-only differences).
- D: <8,8,4,F> vs <8,8,4,T>, <8,8,8,F> vs <8,8,8,T>, <8,8,16,F> vs <8,8,16,T> all MATCH. Listings diverge by one extra

- G: <8,8,8,T,0,15,0> vs <8,8,8,T,0,15,1> both MATCH. G=1 adds dynamic register indexing (`v_movreld_b32`/`v_movrels_b32`, r3).
