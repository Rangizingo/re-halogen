## Kernel math (all MATCH, listing cites in ht_lin.hip)
- Kernarg `w x a K N d su sv y cnt out up`; grid (N/128 row blocks, splits), 256 threads (8 waves). d = 128-column blocks per split; wave w takes d consecutive 16-column tiles.
- Phase 1: x (bf16, optionally silu(x)*up rounded to bf16 when `up != 0`, IEEE divide) times su (f16), 128-point Walsh-Hadamard over (slot bit0, bit1, lane bits 0..4), times 0x3db504f3, to f16 in LDS. First level: lin pairs (e0,e1) plain add/sub and (e2,x3*su3) fused; grp fuses the earlier element. All products are exact in f32 (bf16 8 bits x f16 11 bits), so fused and unfused agree; the negative control for that changes nothing (recorded in the negctl table as an insensitive MATCH).
- Phase 2: weight word windows. Tile words are one little-endian bit string read from the last word down; weight j = 128h+8r+c reads 16 bits at bit `BITS*(255-j) mod 256*BITS` (matches `analysis/closure/ht-decode.md`, now bitwise against the kernel for 3 and 4 bit). Decode = `0x6400 + bytesum(w16*0x83dcd12d)` as f16, then `fma_f16(v, 0x1eee, 0xc931)` (the s6 literal the closure note could not recover is f16 0x1eee), `v_dot2acc_f32_f16` against x pairs in column order, 4 pairs per tile, tiles ascending.
- Reductions: lane h=0 acc + h=1 acc, then waves 0..7 summed from +0.0, then split-K: partials at `y[(split*S+tok)*N + row]`, a per-row-block ticket (`cnt[rb]`, atomic add, last arriver sums splits 0..n-1 from +0.0 and resets the counter).
- Epilogue: 128-point WHT over rows (register levels bit0,1,2 then lane bits 0..3), times 1/sqrt(128), times sv (f16), bf16 RNE (no NaN case) or f32. Tokens beyond `a` are computed from token a-1 in phase 1 and not stored.
- grp: 1-D grid, 4 groups at 0x48 bytes each (offsets in ht_lin.hip), block to (row block, split) by division, optional second output (`out2`, 256-row interleave: rows with idx%512 < 256 go to `out`, the rest to `out2`, token stride N/2), y and counter offsets per group, and rotation-only blocks (block >= rot_start, `rot_out != 0`) that write the f16 rotated x for a K=2560 token (row stride 2560, 20 blocks of 128).
