## Kernel arguments

- Flat qs (`k_attn_qs<A,B>`): q@0 k@8 v@16 stride(i64)@24 gate@32 o@40 sel@48 n@56(unused) m@60 tbl@64 nblk@72 tstride@80. Grid (tokens, 2 kv heads), block 128 (4 waves), 12 q heads per kv head as rows 0..11 of the 16-row WMMA.
- Paged (`qs_bt`, `bt2`, `bt2w`, `bt4`, `bt4x`): q@0 kpool@8 vpool@16 gate@24 o@32 sel@40 n@48 tbl@56 nblk@64 tstride@72.
- Shared facts: len = sel[0]+bx+1, bb = nblk[bx], nk = 4*bb + (len&3). Key i < 4bb lives in page tbl[bx*tstride + i/4], row i&3; later keys live in page len/4 (flat qs: row 4*tbl+i&3, tail row i + (len&~3) - 4bb).
- Pool layouts (from kv.hip): K `p*2048 + g*1024 + (d>>4)*64 + r*16 + (d&15)`, V `p*2048 + g*1024 + 4*d + r` (elements).
- q token stride is 6144 elements, q index `bx*6144 + g*3072 + head*256 + d`. gate and o share one index `bx*6144 + (g*12+head)*256 + d`.
- Epilogue everywhere: merged l, then flat qs `out = bf16((O/l)/(1+expneg(gate)))`, paged `out = bf16((O*(1.0f/l))/(1+expneg(gate)))`, IEEE divisions, expneg and expf are the expanded forms from g07 (fa2).
