## Shared facts (proven by MATCH)

- 10240 conv channels (`v_cmpx_gt_i32 0x2800`), activation rows of 0x5000 bytes (10240 bf16), conv state = 4 bf16 per channel (8 bytes).
- Conv step: new state `{s1,s2,s3,x}`; `acc = fma(s1,w0,0)`, then `fmac` with s2*w1, s3*w2, x*w3; `y = bf16_rne(acc / (1 + exp2(acc * -log2e)))`
  with IEEE division and bf16 RNE without NaN special case (`v_bfe_u32 16,1` + `v_add3_u32 0x7fff`). The vendor's `and 0x10001 / or / add 0x7fff` on the
  old state words is an identity on bf16 bit patterns (compiler artifact of f32->bf16 round trips).
- Gates: `g = softplus(bf16(a) + dt_bias[j]) * -exp2(A_log[j] * log2e)`, `beta = 1/(1 + exp2(bf16(b) * -log2e))`. softplus is the compiler's
  `logf(1 + expf(v))` expansion (passes `v` through when `20 < v`; `v_log_f32`, ln2 split with two fmas, denormal guard) copied instruction for
  instruction (`softplus_v` in dn_gates.hip, dn_step.hip, dn_conv.hip, dn_recur.hip).
- Recurrence (dn_recur): block = value head h (48), 128 threads = state column d, key head kh = h/3 (h%16 when the step kernel's mode is 2).
  Tree-reduced (strides 64..1 through LDS) sums of q^2 and k^2; `rsq` guarded with 2^24 / 2^12 for denormals; q scaled by `rsq(128)` (a runtime
  `v_rsq_f32`, kept opaque with an empty asm so hipcc does not constant-fold it); decay `exp2(g*log2e)`; pass 1 `S' = decay*S`, `kv += S'*k`
  (and in the step kernel `aq += S'*q`, used by mode 3); `delta = beta*(v - kv)`; pass 2 `S'' = fma(delta,k,S')`, `o += S''*q`; the sums are
  sequential fma chains over the 128 rows. Optional gated RMS norm: `fma(sum(x^2), 1/128, 1e-6)`, guarded `rsq`, times weight, times sigmoid(z).
